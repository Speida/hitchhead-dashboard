Einmalige Einrichtung

Du brauchst einen Anthropic API-Key. Einmal eingeben, dauerhaft gespeichert.

1. Gehe zu console.anthropic.com
2. Klick links auf API-Schlüssel
3. Klick auf + Schlüssel erstellen
4. Key kopieren (beginnt mit sk-ant-)
5. Hier einfügen und starten
Der Key wird nur in deinem Browser gespeichert.
Nie weitergegeben, nie auf GitHub sichtbar.
